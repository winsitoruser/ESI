# Security Awareness Training Outline (SEC-PHI-007)

## Audience

All Humanify staff with production or customer-data access.

## Modules (annual + onboarding)

1. Phishing & fake invoice
2. Credential stuffing / password manager
3. OAuth consent phishing
4. Sharing screens / shoulder surfing
5. Incident reporting (`security@humanify.id`)

## Cadence

| Activity | Frequency |
|---|---|
| Onboarding module | Day 1 |
| Refresher quiz | Annual |
| Simulated phishing (SEC-PHI-008) | Semi-annual when program funded |

## Evidence

Quiz completion sheet · phishing campaign report → attach to risk register.
